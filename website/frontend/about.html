Mission SIH - Industrial Fire Detection System

← Back to Map

Overview

This system classifies NASA FIRMS thermal detections in India to distinguish industrial fires and persistent thermal sources from natural fires. It combines satellite thermal data with land-cover and industrial infrastructure datasets using machine learning.

Data Sources

  • NASA FIRMS: VIIRS thermal anomaly detections from NOAA-20 satellite (standard processing product with ~3 month lag)
  • OpenStreetMap: 67,047 industrial infrastructure points (power plants, mines, gas flares, industrial facilities, oil/gas sites, quarries)
  • Land Use Data: 17.6 million land-use points across India (2018-2026)

Classification Model

The system uses a scikit-learn MLPClassifier (neural network) trained on labeled FIRMS detections:

  • Input features (15): latitude, longitude, scan, track, track_scan, FRP, radiation, brightness, bright_t31, final_bright, acquisition time, day/night, confidence, FIRMS type, match distance
  • Output classes (8): Agriculture, Forest, gas_flare, industrial_facility, mine, oil_gas, power_plant, quarry
  • Test accuracy: 67.86% on a random 20% split (random_state 42)
  • Architecture: Single hidden layer with 200 units, ReLU activation, Adam optimizer, early stopping

Labeling Method

Training labels were produced by assigning each FIRMS detection to the nearest land-use or OSM infrastructure point within 2000 meters:

  1. First, match to the nearest land-use point of the same year (within 2000m)
  2. Then, replace with the nearest OSM point if one exists within 2000m and is closer than the land-use match
  3. Detections with no match within 2000m were dropped from training

Important: The model uses latitude, longitude, and match_dist_m as input features, so it learns spatial patterns. This means predictions are influenced by proximity to known infrastructure.

Decision Logic

For each thermal detection, the system follows this decision order:

  1. Volcano rule: If FIRMS type = 1 (active volcano), label as Volcano directly (model not called)
  2. No match: If no land-use or OSM point within 2000m, label as Unclassified (model not called)
  3. MLP classification: For FIRMS types 0, 2, 3 with a match, run the model and use its prediction
  4. Unexpected type: For any other type value, label as Unclassified

Classification Groups

  • Industrial: gas_flare, industrial_facility, mine, oil_gas, power_plant, quarry
  • Natural: Forest, Agriculture
  • Volcano: Active volcanic thermal sources (FIRMS type 1)
  • Unclassified: No nearby infrastructure or unexpected type

FIRMS Types

The FIRMS 'type' field indicates presumed sources:

  • 0: Presumed vegetation fire
  • 1: Active volcano
  • 2: Other static land source
  • 3: Offshore detection

Limitations and Uncertainties

  • Spatial resolution: VIIRS pixels are 375m at nadir, so attribution to a specific facility is uncertain
  • Test accuracy: 67.86% overall; per-class metrics were not computed during training
  • Class imbalance: The gas_flare class relies on very few OSM points, so predictions for this class may be less reliable
  • Labeling assumptions: Training labels assume the nearest point (within 2000m) is the correct source, which may not always be true
  • Data lag: Standard processing FIRMS data has a ~3 month lag; current data through 2026-06-30
  • No validation on ground truth: Model performance is measured on the same labeling method used for training

Technical Details

Training period: 2018-04-01 to 2026-05-31 (5,089,539 detections filtered to 4,101,465 with matches)

Model repository: bazik-0/mission-sih on Hugging Face

Feature engineering:

  • track_scan = scan × track
  • final_bright = brightness × bright_t31
  • radiation = track_scan × FRP
  • confidence encoding: l=300, n=600, h=900
  • day/night encoding: D=0, N=1

Problem Statement

This system addresses Smart India Hackathon 2026 problem statement SIH26162 (NTRO, Disaster Management, Software): AI-based detection and classification of industrial fires and persistent thermal sources using NASA FIRMS, OSM and satellite data.
